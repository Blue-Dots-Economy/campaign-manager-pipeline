HOW A BATCH IS MADE UP
----------------------
A batch has settings, and a list of contacts. Each contact is three things:

    phone         10 digits
    name          the person's name, or "Not Available"
    agent_args    a JSON object - this is where everything else goes

Batch settings: agent_id, name, concurrency, max_retries, retry_after_hrs.

Via the API:
    POST /api/batch                  create it
    POST /api/batch/{id}/contacts    add the contacts
    POST /api/batch/{id}/start       start dialling

There is also POST /api/call for a single call: agent_id + to_number +
agent_args, with an optional scheduled_at. No batch needed.

================================================================================
TRAPS
================================================================================

1. EMPTY VALUES ARE NOT CONSISTENT ACROSS BOTS.
   DKB writes the literal string "Not Available". The seeker bots leave
   location and college_name as empty strings. contact_memory is
   "Not Available" everywhere. The bots read these strings literally, so
   match each bot's own convention per field rather than picking one.

2. recommendations IS A STRING, NOT AN OBJECT.
   It is a JSON array serialised into a string inside agent_args. Passing a
   real array may not be read.

3. CHECK job_id RESOLVES BEFORE SENDING.
   219 apply attempts failed with "Job not found" and 456 with "Invalid or
   missing profile_id" - 79% of all apply failures are breakages like these,
   not people changing their minds.

4. phoneNumber ON DKB IS camelCase.
   Every other key is snake_case. It is also empty in practice; the number
   that gets dialled is the contact's phone, not this field.

5. THE BOTS DECLARE ALMOST NO OUTPUT FIELDS.
   15 of 22 agents have output_fields empty, so the fields that come back
   (drop_reason among them) are invented by the summariser rather than
   specified. If you want reliable structured output, declare it in
   output_fields - the DKB bots do, with 38 keys, and their data is far
   cleaner as a result.
